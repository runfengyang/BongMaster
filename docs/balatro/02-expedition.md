# BongMaster × Balatro 远征战斗系统 · 实施契约（02-expedition）

> 前置文档：`01-design.md`（§1-§15 现状契约）。本文档是远征模式的**唯一实施契约**。
> 核心定位：以真实工作行为为输入、以「活跃日远征」为单局、以消耗品卡牌构筑为
> 核心的生产力 Roguelike。图鉴永久点亮；卡牌局内获得、局终清算。
> 核心循环（业主定调）：**Roguelike 牌组构建 + 老虎机抽牌型**——工作行动
> 生成行动牌堆并积累拉杆次数，每日结算时老虎机从牌堆抽 5 张成牌型计分，
> 原样复用 `engine/evaluate.js` / `score.js` / `jokerEffects.js` 计分体系。
> 卡包经济（业主定调）：**卡包只在远征局内产出与消耗**；图鉴记录战斗中
> 出现过的卡，见过即永久点亮。（模型演进见文末 §16 修订记录。）

## 1. 双系统总览

| 系统 | 状态 | 说明 |
|---|---|---|
| **卡片图鉴**（`/cards`） | 已存在，保留 | 发现即永久点亮，永不熄灭。是收藏与档案馆 |
| **远征卡包经济**（新） | 本文档 | 卡包仅在远征局内产出（节点奖励/Boss 掉落/商店），开出的卡局内生效、局终清算 |

- 图鉴点亮（`collection.discovered`）永久有效；任何卡在战斗中「出现」即点亮

- 局内开包概率、版本 roll 全部沿用 §11/§12 现有引擎档位，不做任何改动。

## 2. 局内卡牌生命周期

- 一切卡牌（小丑/塔罗/星球/幻灵/扑克牌）**局内获得、局内生效、局终清算**。
- 版本（闪箔/全息/多彩/负片）回归**原作语义**：局内数值/栏位加成
  （Foil +50 筹码 / Holo +10 倍率 / Poly ×1.5 / Negative +1 栏位），无耐久含义。

### 2.1 起始构筑（开局 draft）

- 每局开局：1 个小丑包（3 选 1）+ 1 个标准包（5 选 2），即开即选——
  每局从一次小型构筑决策开始，解决冷启动。
- 起始包规格随通关次数升级（§8）。

### 2.2 局内卡包来源

- 普通节点通关：卡包三选一（类型随机）。
- 精英节点通关：Jumbo 档。
- Boss 通关：Mega 档 + 稀有掉落概率。
- 商店节点：研料购买（卡包/临时强化/优惠券，优惠券 E4 全量）。
- 局内开包沿用 §11-§15 概率档位与 PackModal 演出（撕裂/翻牌/细看复用）。

### 2.3 研料（局内货币）

- 来源：节点奖励、经济型小丑（原作金钱语义 → 研料）、当日未使用拉杆 1:1 转化。
- 用途：商店消费。局终清零，不跨局。

### 2.4 局终清算

- 通关/失败/放弃：局内卡牌、研料、牌型等级、临时强化**全部清算**。
- 永久保留：图鉴点亮、通关次数、卡池解锁、起始构筑升级。
- 失败不损失任何永久内容（红线）。

## 3. 远征结构

### 3.1 活跃日规则（红线）

- 一局远征 = **5 个活跃日**，与日历日**彻底解耦**。
- 活跃日定义：当天有 ≥1 个有效行动事件（见 §5.1 有效性规则）。
- 无行动的日子：远征暂停，不推进、不惩罚、不结算。**系统永不惩罚休息**。
- 每日结算时机：次日首次打开应用时（或当日 23:50 若在线），批量结算前一天。

### 3.2 节点路线

```
普通节点 ── 精英节点 ── 商店节点 ── 普通节点 ── Boss
  日1          日2          日3         日4        日5
```

- v1 路线固定（无分支）。主动选择仅发生在：节点奖励（卡包三选一/拿取）
  与商店节点（研料消费）。
- 每个节点 = 一个敌方 HP 池；当日伤害 ≥ 节点 HP 即推进，溢出伤害
  按 50% 结转下一节点（防浪费，鼓励爆发 build）。

### 3.3 远征主题（v1 两个）

| 远征 | 倾向 | Boss |
|---|---|---|
| 论文攻坚 | 奖励同项目连续推进（同花构筑友好） | 分心之墙 |
| 多线救火 | 奖励多项目/多类型（对子/两对构筑友好） | 拖延之墙 |

选远征时展示：目标、Boss 类型与规则、推荐构筑方向、主要奖励。
**玩家按接下来几天的工作计划选远征，不是按收益选。**

### 3.4 通关判定

- 唯一通关条件：第 5 活跃日结算时 Boss HP ≤ 0 **且** 压力 < 5。
- 通关 → 总通关次数 +1、该远征通关数 +1、发奖（Mega 包等）、
  检查卡池与起始构筑解锁（§8）。
- 失败（压力满 5 / 5 活跃日耗尽 Boss 未倒）：局内构筑按 §2.4 清算，
  **永久内容不受任何损失**，解锁进度不变。
- 中途放弃 = 失败，同样只清算局内构筑。

## 4. Boss 设计

### 4.1 Boss 数据结构（`data/expedition/bosses.js`）

```js
{
  id: 'boss_distraction',
  name: '分心之墙',
  hp: [800, 1000, 1200],        // 按远征难度档
  minDamagePerDay: 100,          // 活跃日最低伤害线（未达 → 压力+1）
  rules: [ ... ],                // 见下
  intents: [ ... ],              // 每日意图（当天规则变化）
  art: { bg, motif, accent, pixelMap },  // §4.3
}
```

### 4.2 v1 两个 Boss

**分心之墙**（惩罚换轨）
- 规则：**每次拉杆**抽出的 5 张牌 ≥2 种花色时，每多 1 种花色，
  该次拉杆最终倍率 ×0.85。
- 意图池：「今日第 2 次换轨（行动牌出现第 2 个项目）→ 压力 +1」
  「今日 ♥ 花色削弱（不计入牌型）」「今日所有抽取视为同花色（恩赐日，罕见）」。
- 克制构筑：专注/同花构筑、防削弱卡。

**拖延之墙**（惩罚重复）
- 规则：**每次拉杆**中相同点数的牌第 2 张起点数筹码减半（同类收益递减）。
- 意图池：「今日重复花色 → 压力 +1」「今日顺子倍率 ×1.5（恩赐日）」。
- 克制构筑：多样点数/多花色构筑、成长型卡。

- 压力来源**只有两种**：活跃日伤害 < 最低线；违反 Boss 当日意图。
  其余任何现实行为（休息、没打开应用、任务少）一律不产生压力。

### 4.3 Boss 视觉

- 像素图腾 + 筹码底座：64×64 像素矩阵写在 `art.pixelMap`（或多 emoji
  分层合成），pixelated 3x 放大；m6x11 字体、CRT 衬底，与图鉴同一视觉体系。
- 四状态演出：施法（每日意图横幅 + 前摇 0.3s）→ 受击（shake + 伤害飘字 +
  chunky HP 条消减）→ 施压（推近 5% + 红晕脉冲 + 压力槽点亮）→
  碎裂（复用 PackModal 碎屑系统改配色）。
- 全部复用 PlayingCard/PackModal 动画原语与 sound.js 程序化音效
  （新增 Boss 受击低频 burst + 意图下行滑音两个音色）。
- 形象即规则图解：分心之墙 = 发光屏幕/通知铃铛砌成的墙（霓虹杂色 glitch）；
  拖延之墙 = 贴满「明天」便利贴的墙 + 融化的钟（昏黄灰）。

## 5. 老虎机抽牌型 · 数值核心

### 5.1 行动 → 行动牌堆 + 拉杆次数（`engine/expedition/actionCards.js`）

每个有效行动事件：**今日行动牌堆 +1 张行动牌 且 拉杆次数 +1**。

行动牌 `{ rank, suit, source, taskId }`：

| 真实行为 | rank（点数） | 说明 |
|---|---|---|
| 习惯打卡 | 4（streak ≥7 → 6） | 连续行动 |
| 完成每日任务 | 5（高优先级 7） | 普通行动 |
| 完成项目任务 | 8（高优先级 10） | 项目行动 |
| 清空当日全部每日任务 | Q | 收尾行动 |
| 项目完成/里程碑 | A | 精英行动 |

- suit（花色）= 项目归属：项目任务按 `project_id` 哈希 → ♠♥♣♦；
  无项目行动（打卡/日常任务）固定 ♦。
- 有效性规则（防刷红线）：
  - 当日 00:00 前已存在的任务完成 → 全额 rank；
  - 当日新建当日完成 → rank 减半（向下取整，最低 2）；
  - 完成→撤销→再完成：只计首次；
  - 每日最多 5 张行动牌 / 5 次拉杆（第 6 个起只记录不计分）。
- **工作结构决定牌堆构成，牌堆构成决定牌型概率**：专注日 = 单色浓度高
  = 同花率高；点数多样 = 顺子率高。生产力解释器内核以此保留。

### 5.2 本局牌组（牌组构建本体）

- **抽取池 = 今日行动牌堆 + 本局扑克牌组**（起始 Standard 包 + 局内获得的
  扑克牌，可含增强/蜡封/版本）。
- 扑克牌上的增强/蜡封/版本按**原作语义**生效（Glass ×2 与碎裂、Steel 手牌
  ×1.5、Red 蜡封重触发等，由 score.js 既有逻辑处理）。
- 塔罗改牌类（死神/力量/魔术师等）直接作用于牌组中的牌，恢复原作语义。
- 牌组上限 52 张；节点奖励/商店时可调整构成（弃牌换牌等主动构筑操作
  随 E4 重转机制开放）。

### 5.3 拉杆结算管线（`engine/expedition/dayScore.js`）

每活跃日结算。**每次拉杆**：

```
可播种 RNG 从抽取池抽 5 张（无放回；池不足 5 张时重洗补足）
  → evaluate(hand, modifiers)      【复用 engine/evaluate.js：牌型判定】
  → 基础 筹码/倍率 = 牌型当前等级值   【hands.js 等级，星球升级生效】
  → 逐张计分（rank 筹码 + 增强/蜡封，原作语义）
  → 小丑从左到右触发                【复用 engine/jokerEffects.js + adapter】
  → Boss 规则/意图修正（按本次拉杆）
  → total = chips × mult = 本次拉杆伤害
```

- **当日伤害 = Σ 每次拉杆伤害**；事件流覆盖全部拉杆（UI 演出单位 = 一次拉杆：
  拉杆 → 轮带转动 → 逐格定格 → 牌型爆出 → 小丑连锁触发）。
- 小丑 ctx 由 `engine/expedition/adapter.js` 构造，成长型 state 跨活跃日持久；
  经济型小丑产出研料。
- 个别无法映射的效果在适配层加 `// FIDELITY:` 注释，逐条登记。

### 5.4 消耗牌在战斗中的位置

- **星球（12）**：使用 → 对应牌型等级 +1（原作语义不变），本局有效。
- **塔罗（22）**：改牌类恢复原作语义（作用牌组）；当日类一次性法术按翻译表
  （节制 = 压力 -1；塔 = 重 roll Boss 今日意图；隐者 = 研料 +2 等）。
  全 22 张翻译表在 Phase E2 数据文件逐条落地。
- **幻灵（18）**：强力一次性。灵魂 = 随机传奇入阵容（局内）；黑洞 = 全部牌型
  +1 级；降神 = 复制阵容中 1 张小丑（局内副本）；诅咒 = 销毁 1 张小丑 →
  当日全部拉杆伤害 ×2。
- **增强/蜡封**：活在扑克牌上（Standard 包开出），原作语义，见 §5.2。

### 5.5 数值标定（蒙特卡洛）

- E1 已产出真实数据画像（日均 2.92 抽、同项目集中度 86.6%、散牌日 46.8%）。
  Phase E2 在此基础上做蒙特卡洛模拟：牌堆构成 → 抽取分布 → 日伤害期望/方差。
- 标定目标：裸装日伤害期望 ≈ Boss HP 的 12-15%（必须构筑），合理构筑日
  ≈ 22-28%（5 日稳过）；体验指标：同花日概率 ≥15%（专注日有惊喜感）。
- 所有数值常量集中在 `engine/expedition/balance.js`，禁止散落硬编码。

## 7. 与现有系统的关系

- **保留**：`engine/run.js` 扑克 Run（attic 归档）不动；开包引擎概率档位不动。
- **退役**：远征上线后，现有「打卡/任务 N 次 → 送卡包」滴灌（§11②）退役——
  生产力行为的价值改为：进行中远征的**行动牌 + 拉杆次数**。
  无进行中远征时行动不产生游戏资源（Dashboard 引导开局）。
- **复用为库**：`evaluate.js` / `score.js` / `jokerEffects.js` / `hands.js` /
  `planets.js` 等被远征引擎 import，不改其导出。
- **扩展**：`integration.js` 挂接点 payload 增加远征所需字段（project_id、
  优先级、任务创建时间），新增 `notifyProjectTaskCompleted` /
  `notifyDayCleared` / `notifyProjectMilestone` 三个挂接点。
- **持久化**：远征状态存 `balatro_state` 表新 key（`expedition:*`），
  沿用 500ms 防抖与 localStorage 降级；任何反序列化异常降级为空局，永不抛。

## 8. 解锁与长期进程

长期进程三件套：

1. **通关 → 卡池扩容**（局内卡包池）：
   0 通关 = 基础池（普通 40 + 罕见 20）；1 = 意图池扩充；
   3 = 罕见全量；5 = 稀有 20 解禁；8 = 增强/蜡封入包率提升；
   12 = 传奇相关（灵魂出率提升）；20+ = 终局远征主题。
2. **通关 → 起始构筑升级**：开局包规格提升（Normal → Jumbo → Mega 档）、
   +1 消耗牌栏、+1 小丑栏等（阶梯表 Phase E2 定稿）。
3. **图鉴点亮**：见过即亮，永久收集。

- 解锁只扩充卡池与构筑空间，不做数值膨胀；后期内容提供新解法
  （新 Boss 对应的新构筑方向），不让旧卡失效。
- 赛季/精通/第二能力分支：本期不做，不写桩代码。
